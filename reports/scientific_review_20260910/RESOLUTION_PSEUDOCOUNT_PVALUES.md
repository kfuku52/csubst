# 擬似カウント・ωC P 値と dif 帰無分布の対応

2026-09-10。レビュー ID 2 と ID 4 の実装対応。
[当初計画](PLAN_PSEUDOCOUNT_PVALUES.md)に沿い、観測・帰無の共通変換、
共同カテゴリ生成、反復ごとの prior／alpha 再推定、診断出力を実装した。
使用可能な設定と CLI 例は[利用ガイド](../../docs/PSEUDOCOUNT_PVALUES.md)を参照。

## 修正内容

- 観測と帰無で、同じカウント平滑化・ωC 計算を使用する。
  `observed`／`expected`／`both`、ゼロ、NaN、無限大を両側で揃える。
  非ゼロの小さい prior を観測カウント用の閾値で捨てない。
- `poisson` では4つの排他的なカテゴリを一度ずつ生成し、同じ反復から
  any／spe／dif を集計する。共通成分による共分散を保持し、全イベントが
  specific なら dif カウントは恒等的にゼロになる。
- empirical prior／alpha=auto は、各反復の全枝集合・同じカテゴリ集合から
  同じ共通推定関数で再推定する。E は fitted count null に条件付けて固定する。
- 平滑化・補正を使う検定と共同カテゴリ検定は、最終反復予算を全行で使用する。
  行の間引きによる prior や empirical long-tail 補正の変化を防ぐ。
  ブロック分割、カテゴリ順、行順、途中の反復スケジュールに対する再現性を検証した。
- 独立帰無分布の long-tail 補正では、固定 symmetric alpha を観測・学習用帰無・
  検定用帰無すべてに適用し、同じ frozen map で比較する。
- P 値が比較した統計量、alpha／prior の固定・再推定、有効反復数、未定義反復数を
  `pvalue_*_<stat>` に記録する。補正前の P/Q と対応する診断は `_nocalib` に保存し、
  補正後の Q 値は新しい P 値から再計算する。
- 実 CLI 検証で追加発見した問題も修正した。設定読取りが `dict` に限定されていたため、
  `RunContext` では擬似カウントが無効扱いになっていた。一般の `Mapping` に対応し、
  辞書・実行コンテキストの両経路を回帰テストした。

## 明示的な適用範囲

共同カテゴリ帰無は、既存の Poisson 周辺分布を排他的な4成分で結合する
**枝組合せカウントのモデル**である。原子的な枝の置換履歴を再構成するものではなく、
異なる行や N/S チャネルは fitted means に条件付けて独立とする。
共有枝に由来する行間の依存や、ASR の不確実性を再現したとは主張しない。

- dif および empirical／auto の P 値は Poisson に限定する。
  他の帰無生成器の周辺分布から共同分布を勝手に補わず、明示的に拒否する。
- fitted means から負の成分が必要になる場合や、保存された差分期待値と
  base 期待値が食い違う場合はエラーにする。負の乱数のクリッピングや NaN 除外で代用しない。
- empirical／auto と `independent_null` long-tail の組合せは未対応。
  `empirical` 補正、または補正なしで反復再推定を行う。
- alpha=0 の補正なし base 検定は従来の帰無生成と段階的反復を維持する。
  `pseudocount_report` のみ、mode=none は平滑化として扱わない。

## 独立した条件付き帰無実験

[再実行スクリプト](validate_pseudocount_pvalues.py)は、既知の平均を持つ独立 Poisson
成分から観測データを生成し、別乱数で本実装の帰無反復を生成する。
疎な S と不均一な exposure の2条件、5設定、各250独立データセット、各199帰無反復を使う。
各データセットは8行だが、二項信頼区間には指定した1行だけを採用する。
prior や補正を共有する行を独立な反復として数えない。

これは条件付きカウントモデルの確認であり、アラインメント生成から ASR・モデル推定・
候補選択までの生物学的偽陽性率を較正する実験ではない。

名目5%の結果を示す。括弧内は各条件の二項95%信頼区間で、条件間の多重性は補正していない。

| 条件 | 設定 | any2spe 棄却率（95% CI） | any2dif 棄却率（95% CI） |
| --- | --- | --- | --- |
| 疎な S | 補正なし | 0.0% (0.0%–1.5%) | 0.0% (0.0%–1.5%) |
| 疎な S | symmetric α=1 | 4.4% (2.2%–7.7%) | 2.8% (1.1%–5.7%) |
| 疎な S | empirical α=1 | 5.6% (3.1%–9.2%) | 5.2% (2.8%–8.7%) |
| 疎な S | empirical α=auto | 3.6% (1.7%–6.7%) | 3.2% (1.4%–6.2%) |
| 疎な S | symmetric α=1＋empirical long-tail | 2.4% (0.9%–5.2%) | 2.4% (0.9%–5.2%) |
| 不均一 exposure | 補正なし | 4.0% (1.9%–7.2%) | 4.8% (2.5%–8.2%) |
| 不均一 exposure | symmetric α=1 | 3.6% (1.7%–6.7%) | 4.0% (1.9%–7.2%) |
| 不均一 exposure | empirical α=1 | 5.2% (2.8%–8.7%) | 6.0% (3.4%–9.7%) |
| 不均一 exposure | empirical α=auto | 3.6% (1.7%–6.7%) | 4.8% (2.5%–8.2%) |
| 不均一 exposure | symmetric α=1＋empirical long-tail | 4.4% (2.2%–7.7%) | 3.2% (1.4%–6.2%) |

平滑化を使った条件では、全3カテゴリを含めた名目5%の棄却率は2.4–6.4%。
今回調べた1%・5%・10%水準の全条件で、95%区間の下限が名目水準を超えたものはなかった。
これはこの有限の条件付き帰無実験で過剰棄却の明瞭な兆候を検出しなかったという結果であり、
一般的な較正保証ではない。疎な S の未平滑化統計量は強く保守的だった。
[全結果・信頼区間](pseudocount_null_calibration.json)には any2any と他の名目水準も保存した。

## コミット前の追加監査

追加で次の3経路を修正し、全体テスト1803件を通過した。

1. `output_stats` を CSV 文字列で渡した場合や `output_stat` 別名でも、
   効果量と検定の同じカテゴリ解決関数を使う。dif の共同帰無検証をすり抜けない。
2. 通常の `get_omega` は現在のカウント・設定から推定し直す。
   行や alpha 設定を変更した後に古いキャッシュで観測側だけを計算しない。
3. 前景置換の不足行には、元の解析で推定した prior／alpha を明示的に再利用する。
   不足行のみで再推定した効果量を元の表に混ぜない。データ依存平滑化の P/Q は
   `unavailable_full_population_null` として未定義、反復数ゼロを記録する。

これにより、このタスクで予定した実装・適用範囲の検証は完了した。
上記のモデル制限と、別タスクに分けた科学的較正・選択・ASR 等の課題は残る。
